whl-store.js — layer fetching

Loads E17 page-0382 with latency:'3g' so the streaming order is watchable: source → words → associations → entities, plus the synthetic tiles status. Reload the page to watch the dots progress again. Every downstream section renders from this one store.

import {createStore} from './whl-store.js';
const store = createStore({base:'data', book:'E17', bus, pages:['page-0382'], latency:'3g'});
await store.load('page-0382');   // resolves when text layers settle (tiles may trail)
store.get('page-0382');           // {source, words|glyphs, associations, entities, index, …}
store.status('page-0382');        // {tiles:'ready', source:'ready', …}
store.prefetch('page-0383');
// EB01 → glyphs.json instead of words.json (hardcoded); layers:{pageKey:[…]} overrides

whl-viewer.js — facsimile plane

EB01 columns 44–46 in a scroll-h world with direction:'rtl' — the hieratic scroll reads right-to-left, so col 0044 sits rightmost and next() pans left. Region overlays are switched visible here; hover one and the viewer emits hover on its own bus (log below), a local linker echoes the highlight straight back. Without OpenSeadragon this degrades to a static strip with identical events.

import {createViewer} from './whl-viewer.js';
const viewer = createViewer({el, bus, store, book:'EB01',
  profile:{layout:'scroll-h', direction:'rtl'},
  pages:[{key:'col-0044', url:'../assets/pages/EB01-col-0044.jpg', w:834, h:1600}, …],
  start:'col-0045'});
viewer.goto('col-0046'); viewer.next(); viewer.prev(); viewer.current();
viewer.select(page, region);            // zooms + emits select
viewer.applyHighlight(h); viewer.setRegionsVisible(true);
viewer.addOverlayEl(page, box, el); viewer.destroy();

whl-linker.js — hover/selection brain

Headless. Listens for hover/select, resolves association groups through the store's indexes, and emits one rAF-debounced highlight event carrying weight maps that every pane applies. The readout shows the last highlight payload on the main bus.

import {createLinker} from './whl-linker.js';
const linker = createLinker({bus, store});   // wire once per page
bus.on('highlight', h => { viewer.applyHighlight(h); text.applyHighlight(h); });
// h = {regions:Map<'page/idx',w>, words:Map<'page/r:i',w>, groups:Map<gid,w>}
linker.destroy();
listenshoverhover:clearselectselect:clearlayeremitshighlight {regions, words, groups}

Full composition — viewer + text + linker + store + sidebar

The composition sketch from API.md, live: E17 p.0382 facsimile (single layout), reading pane, and sidebar on the shared bus/store/linker. Hover a region on the image → the text region tints; hover a span in the text → the matching word boxes light on the facsimile. Click either side to select; contents clicks zoom the viewer and scroll the text.

const bus = createBus();
const chrome = mountChrome({title:'…', bus, modes:['study','facsimile'], note:'…'});
const store  = createStore({base:'data', book:'E17', bus, pages:['page-0382'], latency:'3g'});
const viewer = createViewer({el, bus, store, book:'E17', profile:{layout:'single'},
  pages:[{key:'page-0382', url:'../assets/pages/E17-page.jpg', w:1100, h:1600}]});
const text   = createTextPane({el, bus, store, book:'E17', page:'page-0382'});
const side   = createSidebar({el, bus, tabs:{…}});
createLinker({bus, store});
bus.on('highlight', h => { viewer.applyHighlight(h); text.applyHighlight(h); });
store.load('page-0382').then(pd => side.setThisPage(itemsFrom(pd.entities)));
